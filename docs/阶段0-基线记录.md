## 4. 已发现的环境异常（与本轮改动无关，需你知晓）

### 4.1 AI 网关模型名全部改名，配置已失效

`.env` 里配的两个模型名在网关里**都不存在了**：

| `.env` 配置 | 网关实际 | 实测结果 |
|---|---|---|
| `AI_MODEL=deepseek-v4.1-flash-solo` | `deepseek-v4.1-flash` | 原名 404 / 超时 |
| `AI_VISION_MODEL=Doubao-Seed-2.1-Turbo-solo-max` | `Doubao-Seed-2.1-Turbo` | 原名 **502 Bad Gateway** |

`GET /v1/models` 返回 45 个模型，**没有一个是 `-solo` 后缀**。所以：

- 纯文本：用 `deepseek-v4.1-flash` 实测 **5.7s / 6.5s 两次正常返回**
- 视觉：`Doubao-Seed-2.1-Turbo` 实测 **502**；`Doubao-Seed-2.1-Pro` **404**

### 4.2 由此导致 `ocr_test.py` 3/6

```
PASS 扫描件上传成功
PASS 解析任务已消费 1.2s
PASS 解析结果 ok
    实际字段: {'name': '', 'phone': '', 'email': '', 'education': '', 'major': '', 'years_experience': ''}
FAIL OCR 字段命中 ≥5/6  0/6
FAIL 识别出姓名
FAIL 识别出手机
```

**结论：OCR 链路代码没坏，是视觉模型不可用导致降级为"待 OCR"。** 修 `.env` 的模型名即可恢复（属阶段 0 的环境修复，见 TODO 0.5）。
