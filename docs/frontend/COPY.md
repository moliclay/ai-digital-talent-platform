# COPY · 文案 deck

S3 产物 · 2026-11-03
规则：先定文案，再写代码。所有界面文字落到 `src/content/copy.ts`，key 用 `页面.区块.元素`，代码里不出现中文字面量。
语气：短句、具体、可核对。说清"发生了什么、现在能做什么"，不说"我们很智能"。

---

## 1. 声音与硬规则

1. 一句里只做一件事。按钮用动词开头，不用"确定 / 提交"这种空词。
2. 数字必须带单位：份、条、题、分、分钟、年、个、张、人。百分号不留空格（`12.5%`），分数与单位之间留空格（`78 分`）。
3. 错误文案 = 什么失败了 + 现在能做什么。后端 `message` 原样透出时，前面加一句人话。
4. 空态 = 一句现状 + 一个下一步。不写"暂无数据"四个字就结束。
5. 权限文案 = 缺哪个权限 + 找谁 + 回哪。不写"无权访问"就结束。
6. 不承诺不存在的功能：没有导出接口，就不出现"导出"；没有批量删除简历，就不出现"批量删除"。
7. AI 相关一律写清口径：是模型生成还是规则生成，权重多少，是否可复现。
8. 禁用词：赋能、一站式、无缝、极致、颠覆、重塑、生态、抓手、闭环、欢迎回来、立即开启、智能升级、数智化（当形容词用时）。

## 7. 文案与接口的对应（避免编字段）
