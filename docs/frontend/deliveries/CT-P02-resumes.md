# CT-P02 简历智能筛选 · 验收

日期：2026-11-03
路由：`/resumes`
范围：仅重做页面结构与视觉；上传、解析、筛选、详情、队列的业务逻辑仍调用原有接口，未改后端。

---

## 1. 页面结构

```
页头：简历智能筛选 + 上传简历
概览卡：简历库总量 / 已解析 / 队列未完成 / 解析失败 / 解析完成率 + 队列详情
列表卡：关键词 + 学历筛选 + 9 列表格 + 分页
弹窗：简历详情；抽屉：解析队列
弹窗：上传简历
```

变化：

- **队列入口从页头移到概览卡右侧**；页头只保留主操作「上传简历」。
- 新增四指标概览，数据来自真实 `GET /resumes/queue`：已解析、队列未完成、解析失败、解析完成率。
- 关键词、学历改为**可见 label**，搜索按钮升到 40px，与输入框同高。
- 概览在列表出错时显示「暂无」，不再用 0 冒充真实数据。
- 宽屏内容最大宽 1600；1910 下铺满主区。

## 3. 五态

| 态 | 触发 | 结果 |
|---|---|---|
| loading | 首屏 | 表格骨架 8 行；概览用接口值 |
| empty | 搜索无结果 | 「没有匹配的简历」+ 清空筛选 |
| error | 拦截列表请求 | 「简历列表没取到」+ 重试；概览总量显示「暂无」 |
| 无权限 | `pm_wang` 进入 | 「没有查看简历的权限」+ `resume:view` 说明 |
| 超限 | 上传 >20 份 / >10MB | 文件级逐条原因，不静默丢弃 |

上传弹窗、简历详情弹窗、队列抽屉均已按浅色主题复核。

## 6. 已知

1. **表格列宽仍由固定宽度控制**，极长专业/文件名会省略；已有 `title` 悬浮提示，后续可做列宽拖拽。
2. **概览的“已解析/失败/完成率”来自解析队列**，不是简历表按状态聚合；若队列任务被清理，数字可能与列表状态不完全一致（后端口径问题，前端未伪造）。
3. **移动端导航为图标模式**，依赖 `title`/`aria-label`；不做抽屉菜单。
4. 无权限页仍显示页头与上传按钮区域，但上传按钮受 `resume:create` 控制，`pm_wang` 不会看到。
