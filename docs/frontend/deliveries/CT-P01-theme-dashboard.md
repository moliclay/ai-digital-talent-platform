# CT-P01 全站浅色 + 工作台 · 验收

日期：2026-11-03
范围：**全站主题切换为 Corporate Trust 浅色**，并按同一套视觉重构**工作台**。其余页面只跟随令牌变色，布局等后续逐页重构。

## 1. 全站主题（本次一次性切换）

| 项 | 之前 | 现在 |
|---|---|---|
| 主题 | 深色值班仪表，青色强调 | Corporate Trust 浅色，Indigo/Violet 强调 |

语义令牌整体重映射，所有页面、组件、表格、弹层自动跟随；`dark` 令牌保留在 `tokens.json` 但不再启用。当前 **497 个令牌**。

## 2. 工作台改了什么

- **页头**：工作台标题 + 实时摘要，右侧「上传简历」入口。
- **KPI**：4 张白色统计卡，图标徽章 + 数字 + 口径说明；不再用分隔线长条。
- **主区**：解析队列 / 最近一次匹配双卡，**等高对齐**；窄屏堆叠。
- **最近操作**：全宽表格，保持原有权限（仅 admin/hr 可见）。
- 强调色只用于图标、进度条、链接、选中态；无渐变大面积铺底、无发光动画。
- 内容最大宽从 1180 提到 1600（`--layout-wide`），1910 宽屏下铺满主区；KPI 数值右对齐，避免宽卡片只剩左侧一坨。

数据未改，仍是真实接口：

```
简历总数 6 / 已解析 6 / 在招岗位 2 / 队列待处理 0
最近匹配：高级算法工程师(AI平台部) 6 人，平均 46.7，合格线 70，通过 2 / 未过 4 / 33%
队列：已完成 6，其余 0
```

## 7. 已知

1. **全站只统一了主题与壳层**；P02–P16 的页面布局仍是旧结构，后续逐页重构。
2. **主题切换已移除**，全站浅色；如果之后要恢复深色，需要重新设计一套深色 Corporate Trust，而不是回退旧值班仪表。
