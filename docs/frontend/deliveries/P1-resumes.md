## 1. 已完成

### 1.1 列表

- 默认只显示现行简历；工具栏新增「显示历史版本」开关。
- 开关写入 URL `?history=1`，可刷新/分享；开时 8 条，关时 6 条。
- 姓名列新增：
  - `已转正` 徽标（`employee_user_id` 非空）；
  - `已被新版本替代` 徽标（`is_current=false`）；
  - 旧版整行灰底。
- 新增「测评」列：`exam_summary` 三态徽标；多条时显示通过数/总数。
- 旧版姓名点击会打开 `superseded_by` 的现行版本，不会误开旧版编辑。

### 1.2 疑似重复

- 调 `/resumes/identity/suspected`，当前演示库 2 组：陈宇、王峰。
- 黄色提示条 + 「查看分组」弹窗；组内候选人可按 id 打开详情。
- 无自动合并按钮。
- 「重新计算身份」二次确认调 `POST /resumes/identity/reconcile`，只重算、不删除。

### 1.3 详情弹窗两栏

880px 居中弹窗改为：

```
主栏：基本信息 / 技能 / 优势 / 解析记录 / 简历原文
侧栏：身份与版本 / 测评状态 / 转为正式员工
```

- 宽屏两栏，≤900px 堆叠。
- 身份时间轴显示现行/历史版本、文件名、时间；点击历史版本可切换查看；旧版禁止编辑。
- 测评状态列出试卷、受众、分数/合格线、deadline；已提交可跳成绩页；空态给出去测评页入口。
- 转正按钮只在 `resume:edit` 且有手机号、未转正、现行版本时出现。
- 无手机号时禁用并提示；旧版禁止转正；已转正显示状态。

### 1.4 转正建号

- 二次确认弹窗：「将用简历手机号创建员工账号，并授予培训成长权限。初始密码只显示一次。」
- 成功后打开一次性密码弹窗：账号 = 手机号，初始密码只读 + 复制按钮 + 醒目提示。
- 关闭后清空密码 state，不写 localStorage。
- 400/409 显示后端 message；成功刷新详情与列表。

## 5. 已知

1. 概览「已解析 8」是队列任务数，当前列表 6 是现行简历数；两个口径不同，页面未强行统一。
2. 测评摘要当前全为「未测评」；绑定/提交后的 assigned/submitted 展示要在 P3 联调。
3. 转正测试会真实创建员工账号；测试账号的一次性密码未保留。P4 如需登录验证，应使用客户提供的测试账号或重新生成一个可记录的账号。
4. P1 没有做「部门选择」；转正沿用后端默认部门。
5. 详情侧栏在宽屏下比主栏短，底部留白是双栏内容长度差异，不是加载缺失。
