# CT-P06 人才画像 · 雷达图重构 · 验收

日期：2026-11-03
路由：`/talent-profiles`
范围：按 Corporate Trust 浅色主题重做列表卡片与详情弹窗；核心变化是把原来的五行能力条换成**五维雷达图**。未改后端，未新增依赖。

---

## 1. 雷达图

新增 `src/pages/talent-profiles/radar-chart.tsx`，纯 SVG，无图表库：

- 五个能力维度：技术深度、工程能力、业务理解、协作沟通、成长性。
- 0-100 分映射到五边形半径；25/50/75/100 四层网格。
- 数据区域用品牌 Indigo 半透明填充 + 2px 描边，最弱项也能看出轮廓。
- **最强维度**用 Violet 实心点 + 加粗标签标出，卡片下方同时显示「最强维度 / 分数」。
- SVG `role="img"`，`aria-label` 包含姓名和五维分值，不只靠颜色传达信息。
- 标签、数值、网格全部走语义令牌；没有硬编码颜色、字号或尺寸。

## 2. 页面布局

- 1910：三列卡片，宽 1600 铺满；一屏能横向对比 3 人。
- 1440：三列卡片，雷达图 320px，信息密度优先。
- 1200 以下：两列；860 以下：单列。
- 卡片结构：姓名/类型/AI 徽标 → 雷达图 → 摘要 → 最强维度 → 标签 → 查看画像。
- 页面顶部保留搜索、搜索按钮、生成画像；列表上方显示「共 6 张」和雷达图例。
- 详情弹窗：大雷达图 + 两列维度分数，再往下才是优势、待验证、用人建议、测评证据。

## 7. 已知

1. 1440 三列时摘要仍按 2 行截断，信息密度优先；1910 三列宽度更舒展。
2. 雷达图只画 `abilities`，没有把 `exam_evidence` 的“简历 vs 测评”叠加成双层雷达；接口有数据，但当前页面保持单层合成值。
3. 画像维度若少于 3 个，组件会自动不渲染雷达（当前数据固定 5 维，不会触发）。
4. 403 文案只写「人才画像查看」中文权限名，没有显示 `talent:view` 代码；与 P02 的展示口径略有差异。
