# S6 交付说明 · 题库文件导入 + AI

> 需求⑥ ｜ 完成 2026-11-04 ｜ 回归 `s6_import_test.py` **20/20**

## 1. 需求原文

> 另外，题库支持直接导入一个文件，这个地方需要接入ai能力。

## 2. 三段式设计（为什么不「上传即入库」）

```
文件 → 文本 → AI 抽取（失败则规则解析）→ 草稿 + warnings → 人工确认 → 落库
```

AI 抽题**一定会出错**（漏答案、选项错位、凭空加题）。直接入库等于把脏数据写进生产题库，
而且错了没法改。所以中间必须有「人工确认」这一步，草稿可编辑后再提交。

## 3. 支持的格式

| 格式 | 处理方式 |
|---|---|
| `txt` / `md` / `csv` | 直接解码（utf-8 → gb18030 → utf-16 依次尝试） |
| `docx` | python-docx（段落 + 表格） |
| `pdf` | pypdf，**扫描件不支持**（无文本层 → 返回提示） |
| `xlsx` | openpyxl + **按表头识别列结构** |

上限：单文件 10MB、文本 12,000 字、单次 200 题。

### 3.1 xlsx 为什么要单独做

表格是**列结构**：

```
题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 分值 | 分类
```

按「行」切分的规则解析器读不懂。所以做了 `_xlsx_rows()` + `_HEADER_ALIASES` 表头别名映射：

| 字段 | 认得的表头 |
|---|---|
| 题型 | 题型 / 类型 / 题目类型 |
| 题干 | 题干 / 题目 / 问题 / 内容 |
| 答案 | 答案 / 正确答案 / 参考答案 |
| 分值 | 分值 / 分数 / 得分 |
| 难度 | 难度 / 难易度 |
| 分类 | 分类 / 维度 / 知识分类 |
| 选项 | 选项A~F / A~F / 选项1~6 |

认不出表头时退回按行拼接，效果会差（已在已知限制里写明）。

## 4. AI 抽取

Prompt 硬约束：

> 你是题库录入助手。只做「结构化」，**不新增、不改写、不补题**。原文有几道题就输出几道。
> 找不到答案就 answer 留空，不要猜。

输出严格 JSON 数组，字段固定。AI 超时/失败 → `source=rule` 降级，**不阻断导入**。

## 5. 校验规则（AI 与规则共用）

| 规则 | 处理 |
|---|---|
| `content` 为空 | 丢弃，记 warning |
| 单选/多选但选项 < 2 | **降级为填空题**，记 warning |
| 答案不是选项字母（如 `Z`） | 保留但标 `needs_review: true` |
| `score` 为 0 | 按题型默认（选择 10 / 填空 10 / 简答 20） |
| `knowledge_category` 为空 | 按关键词映射五维词表猜 |

**关键点**：校验放在 `_validate()` 里，AI 结果和规则结果都过这一遍。
否则 AI 返回的错答案就没人拦。

## 6. 接口

### 6.1 上传生成草稿

```
POST /api/question-banks/{bank_id}/import   (exam:create)
multipart/form-data, 字段名 file
```

响应：

```json
{
  "source": "ai | rule",
  "bank_id": 8, "bank_name": "S6导入验证题库", "filename": "题库样例.txt",
  "parsed_count": 5,
  "draft": [{question_type, content, options, answer, score,
             knowledge_point, knowledge_category, difficulty, analysis, needs_review}],
  "warnings": ["第 1 题答案「Z」不是选项字母，请人工核对",
               "第 2 题选项少于 2 个，已按填空题处理"],
  "text_preview": "...", "text_length": 812, "ai_available": true
}
```

**不落库**。

### 6.2 确认导入

```
POST /api/question-banks/{bank_id}/import/confirm   (exam:create)
{ "questions": [ ...草稿（可改过）... ] }
→ { "created": 5, "skipped": 0, "failed": [], "failed_count": 0, "bank_total": 5 }
```

- **同题干自动跳过**（幂等，重复点确认不会重复插入）；
- `failed` 逐题返回失败原因；
- 题库 `total_questions` 同步更新。

## 7. 实测输出

```
★ txt 导入返回草稿 — source=ai parsed=5
★ 四种题型都识别到 — ['single_choice','single_choice','multi_choice','fill_blank','essay']
多选题答案保留多选 — A,B,D
★ 确认落库 — created=5 skipped=0 failed=0
★ 重复导入幂等（同题干跳过） — created=0 skipped=5
★ 答案不在选项内 → 标 needs_review
★ 选项不足 2 个 → 降级填空题

★ warnings 逐条点名 — 3 条
★ docx 导入可用 — parsed=5 source=ai
★ xlsx 导入可用 — parsed=2
不支持的格式 → 400；空文件 → 400；员工 → 403
```

## 8. 实施中修掉的 bug

### 8.1 空题号把下一题吞并（真 bug）

规则解析原来要求题干 ≥4 字符才开新题。遇到 `3.`（空题干）不匹配 → 被并进**上一题**的题干，
导致上一题选项数虚增、后续题型判断错、`needs_review` 标错。

修法：**题号行一律 flush**，空题干交给 `_validate` 丢弃。

验证（修前 / 修后）：

```
修前：2 题，第 2 题 single_choice（3 个选项，把空题号的空行并进去了）
修后：3 题，第 2 题 fill_blank（1 个选项 → 降级），第 3 题被丢弃
```

### 8.2 答案无字母未标记

`Z` 不在 A–H 范围，正则 `\b([A-H])\b` 匹配不到 → 原来不标记。改成**匹配不到也标 `needs_review`**。

### 8.3 xlsx 读不懂

见 3.1。

### 8.4 AI 模型名失效

网关把 `-solo` 后缀全部下线：

| 原值 | 新值 | 实测 |
|---|---|---|
| `deepseek-v4.1-flash-solo` | `deepseek-v4.1-flash` | ✅ 1.6s |
| `Doubao-Seed-2.1-Pro-solo-max` | `Doubao-Seed-2.1-Pro` | 404（网关侧仍缺） |
| `Doubao-Seed-2.1-Turbo-solo-max` | `Doubao-Seed-2.1-Turbo` | 502（网关侧仍缺） |

`.env` 与 `config.py` 默认值都改了。**注意 `.env` 会覆盖 `config.py`**，改一处不够。

## 9. 依赖

`openpyxl 3.1.5`（清华镜像安装，直连 pypi 断连）。

## 10. 已知边界

- PDF 扫描件不支持（需 OCR）；
- xlsx 依赖表头，认不出时效果差；
- AI 抽取质量受模型限制，复杂排版（跨页、多栏）仍可能出错 → 所以必须人工确认；
- 导入的是「题」，不自动建卷（建卷仍需 `/api/exams`）。
